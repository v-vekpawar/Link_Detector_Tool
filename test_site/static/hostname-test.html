🔤 Hostname Target Testing

This page helps you verify that the tool correctly classifies links when the target URL uses a hostname instead of a literal IP address. The server is reachable as both 127.0.0.1:5050 (IP) and localhost:5050 (hostname) — scanning each gives different classification results for the same set of links.

When scanned via IP
http://127.0.0.1:5050/static/hostname-test.html

127.0.0.1/... same
localhost/... internet
192.0.2.99/... ip_based
example.com internet
army.mil excluded

When scanned via hostname
http://localhost:5050/static/hostname-test.html

127.0.0.1/... ip_based ✓
localhost/... same ✓
192.0.2.99/... ip_based
example.com internet
army.mil excluded
✅ The key difference is in rows 1 and 2. When the target is a hostname, 127.0.0.1 flips to ip_based and localhost becomes same.

📋 Step-by-Step Test Instructions

Follow these steps to verify the hostname classification changes:

Step 1

Run a Static scan with target http://127.0.0.1:5050/static/hostname-test.html. Confirm 127.0.0.1:5050 link → same (not in findings), localhost:5050 → internet.

Step 2

Run a Static scan with target http://localhost:5050/static/hostname-test.html. Confirm 127.0.0.1:5050 link → ip_based, localhost:5050 → same (crawled, not in findings).

Step 3

Confirm army.mil link never appears in results for either scan. Confirm example.com appears as internet in both scans.
